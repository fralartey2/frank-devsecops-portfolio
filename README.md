# 🌐 Build Your Own Serverless DevSecOps Portfolio

This project demonstrates how I built and deployed my personal DevSecOps portfolio using only static web technologies and GitHub Pages—no web server required.

---

## ✅ Step 1: Create the Portfolio

I built a responsive single-page portfolio using:

- HTML5
- CSS3
- JavaScript

The portfolio includes:

- Professional profile
- About Me
- Technical Skills
- Professional Experience
- Credentials
- Core Traits
- Downloadable Resume
- GitHub & LinkedIn links

## ✅ Step 3: Upload to GitHub

Create a GitHub repository.

Example:

```
frank-devsecops-portfolio
```

Initialize Git and push the project.

```bash
git init

git add .

git commit -m "Initial DevSecOps portfolio"

git branch -M main

git remote add origin https://github.com/fralartey2/frank-devsecops-portfolio.git

git push -u origin main
```

---

## ✅ Step 4: Publish with GitHub Pages

Open your repository.

Navigate to:

```
Settings
      ↓
Pages
```

Configure GitHub Pages:

```
Source:
Deploy from a branch

Branch:
main

Folder:
/ (root)
```

Click **Save**.

GitHub automatically builds and publishes the website.
